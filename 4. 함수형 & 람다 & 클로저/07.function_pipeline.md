## 📘 pipeline 구현하기
- C++에서는 템플릿과 람다를 활용해서 비슷한 구조를 만들 수 있음

### 📌 기본 pipeline 함수
```cpp
template <typename... Funcs>
auto pipeline(Funcs... funcs) {
    return [=](auto input) {
        return ( ... | [=](auto val) { return funcs(val); } )(input);
    };
}
```

- 하지만 이건 C++20의 operator| 오버로딩이 필요해서 복잡해질 수 있음.
- 실전에서는 단순한 compose 체인으로 구현하는 게 더 일반적.

### 📌 실전 예제: compose로 pipeline 구성
```cpp
#include <iostream>
#include <string>
#include <algorithm>

//compose
template <typename F, typename G>
auto compose(F f, G g)
{
    return [f = std::move(f), g = std::move(g)]<typename... T0>(T0&&... args) mutable
        -> decltype(auto)
    {
        return f(
            g(std::forward<T0>(args)...)
        );
    };
}


//pipeline
template <typename F, typename... Rest>
auto pipeline(F f, Rest... rest)
{
    if constexpr (sizeof...(rest) == 0)
    {
        return f;
    }
    else
    {
        return compose(
            pipeline(std::move(rest)...),
            std::move(f)
        );
    }
}
```
```cpp
int main() {

    auto trim = [](std::string s)
    {
        // 앞쪽 whitespace 제거
        s.erase(
            s.begin(),
            std::find_if(
                s.begin(),
                s.end(),
                [](unsigned char c)
                {
                    return !std::isspace(c);
                })
        );

        // 뒤쪽 whitespace 제거
        s.erase(
            std::find_if(
                s.rbegin(),
                s.rend(),
                [](unsigned char c)
                {
                    return !std::isspace(c);
                }
            ).base(),
            s.end()
        );

        return s;
    };

    auto to_upper = [](std::string s)
    {
        std::transform(
            s.begin(),
            s.end(),
            s.begin(),
            [](unsigned char c)
            {
                return static_cast<char>(std::toupper(c));
            });

        return s;
    };


    auto add_prefix = [](std::string s)
    {
        return std::string("[Transform] ") + s;
    };

    auto process = pipeline(
            trim,
            to_upper,
            add_prefix
        );

    std::string input = "   Hello World   ";
    std::cout << process(input) << std::endl; // 출력: [Transform] HELLO WORLD

    return 0;
}
```


### 📌 핵심 요약
| 구성 요소 | 설명 | 
|----------|-----|
| compose(f, g) | f(g(...)) 형태로 함수 합성 | 
| pipeline(f1, f2, f3) | f3(f2(f1(x))) 형태로 함수 연결 | 
| 람다 함수들 | 각각의 처리 단계 (예: trim → to_upper → add_prefix) |
