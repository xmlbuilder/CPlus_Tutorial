### 1. 먼저 기억할 전체 흐름

```text
교재의 L9 직교배열: 9회 × 4인자(A,B,C,D), 각 인자 3수준
                      │
                      ├─ ANOM: 수준별 응답 평균
                      │      ├─ 전체 평균 = -41.6666667 dB
                      │      ├─ A: [-20, -45, -60]
                      │      ├─ B: [-30, -40, -55]
                      │      ├─ C: [-50, -35, -40]
                      │      └─ D: [-45, -40, -40]
                      │
                      └─ ANOVA: 변동(SS)을 인자별로 분해
                             ├─ Total SS = 3800
                             ├─ A SS = 2450, B SS = 950
                             ├─ C SS = 350,  D SS = 50
                             └─ C,D를 Error로 수동 풀링
                                    └─ Error MS = 400 / 4 = 100

예측에 유지한 인자: A, B
  ├─ 최적: A1 B1 → 예측 S/N = -8.333333 dB
  ├─ 기준: A2 B2 → 예측 S/N = -43.333333 dB
  ├─ 개선량 = +35 dB
  └─ 확인실험을 4회 실시한다고 가정
        ├─ 유효 표본수 = 1.8
        ├─ 차이의 분산 = 80.555556
        └─ ±2σ = ±17.95055 dB
```

### 먼저 구분할 개념

- **ANOM(Analysis of Means):** 인자의 수준별 평균을 비교한다. 어느 수준에서 S/N비가 높은지 살펴본다.
- **ANOVA(Analysis of Variance):** 전체 변동을 인자별 변동과 잔차 변동으로 나눈다. 제곱합(SS), 자유도(DF), 평균제곱(MS), F값을 계산한다.
- **Pooling(풀링):** 영향이 작다고 판단한 인자의 변동과 자유도를 **오차항으로 합치는 분석 선택** 이다. 해당 인자가 실험에서 사라지는 것은 아니다.
- **Prediction(예측):** 분석에 유지한 주효과의 합으로 특정 수준 조합의 평균 응답을 추정한다.
- **Confirmation(확인실험):** 새로 측정한 결과를 예측과 비교한다. 원래 L9 실험 결과를 그대로 확인실험이라고 부르면 안 된다.


## 2. 실험계획의 의미와 기준조건

### 2.1 교재 스캔의 수준 설정

- 교재에서 설명한 기존 공정조건과 변경 수준은 다음과 같다.

| 인자 | 의미 | Level 1 | Level 2 | Level 3 | 교재에서의 원래 조건 |
|---|---|---|---|---|---|
| A | 온도 | $T_0-25$ | $T_0$ | $T_0+25$ | **A2** |
| B | 압력 | $P_0-200$ | $P_0$ | $P_0+200$ | **B2** |
| C | 준비 시간 | $t_0$ | $t_0+8$ | $t_0+16$ | **C1** |
| D | 세척 방식 | None | CM2 | CM3 | **D1** |
