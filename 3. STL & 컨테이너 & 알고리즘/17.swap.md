## 📘 std::swap 개요
- std::swap은 두 변수의 값을 교환하는 함수입니다. STL 컨테이너, 기본 타입, 사용자 정의 타입 모두에서 사용할 수 있습니다.
```cpp
std::swap(a, b); // a와 b의 값을 교환
```

### 📌 코드 예제
```cpp
#include <vector>
#include <iostream>
#include <algorithm> // std::swap

int main() {
    std::vector<int> a = {1, 2, 3, 4, 5};
    std::vector<int> b = {4, 5, 3, 4, 2, 2, 0};

    std::swap(a, b);

    std::cout << "=== a ===" << std::endl;
    for (auto item : a) std::cout << item << std::endl;

    std::cout << "=== b ===" << std::endl;
    for (auto item : b) std::cout << item << std::endl;

    return 0;
}
```


### 📌 설명
| 항목 | 설명 |
|------|---------| 
| 기능 | 두 변수의 값을 교환 | 
| 헤더 | \<algorithm\> | 
| 요구사항 | C++11 이후: MoveConstructible, MoveAssignable | 
| 사용 가능 타입 | 기본 타입, STL 컨테이너, 사용자 정의 타입 | 



### 📌 고급 활용 옵션
#### 🔹 1. 사용자 정의 타입에서 swap 오버로드
struct MyData {
    int x, y;
    void swap(MyData& other) {
        std::swap(x, other.x);
        std::swap(y, other.y);
    }
};


#### 🔹 2. std::iter_swap
- 반복자 위치의 값을 교환할 때 사용
```cpp  
std::iter_swap(vec.begin(), vec.end() - 1);
```

#### 🔹 3. std::exchange (C++14 이상)
- 값을 교환하면서 이전 값을 반환
```cpp
int old = std::exchange(x, 100); // x는 100으로 바뀌고 old는 이전 값
```

#### 🔹 4. 조건부 swap
```cpp
if (a.size() < b.size()) {
    std::swap(a, b);
}
```


### 📌 성능 팁
- std::swap은 내부적으로 move semantics를 사용하므로 큰 객체도 효율적으로 교환 가능
- 사용자 정의 타입에서는 swap을 직접 정의하면 더 빠르게 동작할 수 있음
- std::swap을 오버로드할 경우 std::swap을 명시적으로 호출하는 것이 좋음:
```cpp
using std::swap;
swap(myObj1, myObj2);
```

## 📘 사용자 정의 클래스 객체 간 swap

- 같은 클래스의 두 객체가 가진 내용을 서로 교환할 수 있습니다.
- swap 전용 `operator`는 없습니다. 이동 생성자·이동 대입 연산자를 사용하거나, 직접 `swap` 함수를 정의합니다.
- 객체 자체의 주소는 바뀌지 않고, 각 객체가 보유한 내용이 교환됩니다.

### 📌 1. 기본 std::swap 사용

```cpp
#include <utility>
#include <vector>

struct MeshData {
    int id = 0;
    std::vector<double> values;
};

void Example() {
    MeshData a;
    a.id = 1;
    a.values = {10.0, 20.0};

    MeshData b;
    b.id = 2;
    b.values = {30.0, 40.0, 50.0};

    std::swap(a, b);
    // a: id = 2, values = {30.0, 40.0, 50.0}
    // b: id = 1, values = {10.0, 20.0}
}
```

### 📌 동작 원리

일반적인 `std::swap`은 개념적으로 다음 순서로 동작합니다.

```cpp
MeshData temp(std::move(a)); // 이동 생성자
a = std::move(b);          // 이동 대입 연산자
b = std::move(temp);       // 이동 대입 연산자
```

- 위 클래스는 컴파일러가 생성하는 이동 연산을 사용할 수 있으므로 별도의 연산자 구현이 필요하지 않습니다.
- `std::move` 자체가 데이터를 이동시키는 것은 아닙니다. 이동 연산을 선택할 수 있도록 표현식의 종류를 바꿉니다.
- 이동 연산이 없더라도 복사 생성·복사 대입이 해당 호출을 받아들일 수 있으면 복사로 처리될 수 있습니다.
- 소멸자나 복사 연산을 직접 선언하면 암시적 이동 연산이 생성되지 않을 수 있으므로 확인해야 합니다.
- 원시 포인터로 자원을 소유하는 클래스는 기본 복사·이동만으로 안전해지지 않습니다. 소유권을 별도로 설계해야 합니다.

### 📌 2. 클래스에 멤버 swap 직접 구현

객체의 교환 방법을 직접 정하고 싶다면 멤버별로 교환하는 함수를 작성합니다.

```cpp
#include <iostream>
#include <utility>
#include <vector>

class Mesh {
public:
    Mesh(int id, const std::vector<double>& values)
        : id_(id), values_(values) {
    }

    void swap(Mesh& other) noexcept {
        std::swap(id_, other.id_);
        values_.swap(other.values_);
    }

    // 비멤버 함수입니다. private 멤버에도 접근할 수 있습니다.
    friend void swap(Mesh& a, Mesh& b) noexcept {
        a.swap(b);
    }

    void Print() const {
        std::cout << "id = " << id_ << ", values =";
        for (double value : values_) {
            std::cout << ' ' << value;
        }
        std::cout << '\n';
    }

private:
    int id_;
    std::vector<double> values_;
};

int main() {
    Mesh a(1, {10.0, 20.0});
    Mesh b(2, {30.0, 40.0, 50.0});

    a.swap(b); // 멤버 swap 직접 호출

    a.Print(); // id = 2, values = 30 40 50
    b.Print(); // id = 1, values = 10 20

    using std::swap;
    swap(a, b); // friend swap 선택 → a.swap(b) 호출

    a.Print(); // id = 1, values = 10 20
    b.Print(); // id = 2, values = 30 40 50
}
```

### 📌 설명

| 항목 | 설명 |
|------|------|
| `void swap(Mesh& other)` | 두 객체의 멤버를 직접 교환하는 함수 |
| `friend void swap(Mesh& a, Mesh& b)` | 클래스의 멤버가 아닌 사용자 정의 swap 함수 |
| `values_.swap(other.values_)` | vector 원소를 하나씩 복사하지 않고 내부 저장 공간을 교환 |
| `noexcept` | 이 함수에서 예외가 밖으로 전파되지 않는다는 명시 |
| `using std::swap;` | 표준 swap을 기본 후보로 사용할 수 있게 함 |
| `swap(a, b);` | 인자 타입과 관련된 사용자 정의 swap도 함께 검색 |

위 예제의 `int`와 기본 allocator를 사용하는 `std::vector<double>`는 예외 없이 교환할 수 있으므로 `noexcept`를 붙였습니다. 다른 멤버가 추가되면 해당 멤버의 교환도 예외를 발생시키지 않는지 확인해야 합니다.

### 📌 3. 호출 방법에 따른 차이

| 호출 | 선택되는 동작 |
|------|-------------|
| `a.swap(b)` | 직접 정의한 멤버 swap |
| `using std::swap; swap(a, b);` | 사용자 정의 비멤버 swap을 검색하고, 적합한 것이 없으면 표준 swap 사용 |
| `std::swap(a, b)` | 위 Mesh 예제에서는 표준 기본 템플릿의 이동 생성·이동 대입 사용 |

`swap(a, b)`가 인자 타입과 관련된 함수를 찾는 규칙을 ADL(Argument-Dependent Lookup)이라고 합니다. 클래스 내부의 friend 정의는 이 규칙으로 발견됩니다.

**멤버 swap만 정의한다고 std::swap이 자동으로 그 멤버 함수를 호출하는 것은 아닙니다.** 사용자 정의 함수를 활용하려면 직접 `a.swap(b)`를 호출하거나 `using std::swap; swap(a, b);` 패턴을 사용합니다.

사용자 정의 비멤버 swap은 클래스와 같은 네임스페이스에 두는 방식이 일반적입니다. 위 friend 방식도 이에 해당하며, `namespace std`에 일반 함수 오버로드를 추가하지 않습니다.

### 📌 4. 객체 교환과 포인터 교환의 차이

```cpp
Mesh a(1, {10.0, 20.0});
Mesh b(2, {30.0, 40.0, 50.0});

Mesh* pa = &a;
Mesh* pb = &b;

a.swap(b);        // a와 b의 내용 교환. pa는 계속 a를 가리킴
std::swap(pa, pb); // 포인터 값 교환. 이제 pa는 b를 가리킴
```

| 교환 대상 | 결과 |
|-----------|------|
| 객체 `a`, `b` | 객체 주소는 유지되고 내용이 교환됨 |
| 포인터 `pa`, `pb` | 가리키는 대상이 교환되고 객체 내용은 그대로 유지됨 |

vector의 원소를 가리키던 포인터·참조는 swap 후에도 같은 원소를 가리키지만, 그 원소는 반대쪽 컨테이너 소속이 됩니다. 객체를 가리키는 포인터와 내부 원소를 가리키는 포인터는 구분해야 합니다.

### 📌 5. 구현 시 주의사항

- 전체 내용 교환이 목적이면 배열뿐 아니라 개수, 상태값, 캐시 등 관련 멤버도 함께 교환합니다.
- ID를 객체의 고정된 정체성으로 사용하는 설계라면, ID까지 교환할지 먼저 결정합니다. 위 예제는 ID도 내용의 일부로 취급합니다.
- 자신의 다른 멤버나 내부 버퍼를 가리키는 포인터가 있으면 단순한 멤버 교환 후에도 관계가 유효한지 확인합니다.
- 기반 클래스가 있다면 기반 클래스의 상태도 교환 대상인지 확인합니다.
- `noexcept` 함수에서 예외가 밖으로 나오면 프로그램이 종료되므로 무조건 붙이지 않습니다.
- 이 문서의 예제는 같은 타입의 객체끼리 교환합니다. 서로 다른 클래스 타입은 공통 상태의 의미를 정한 별도 함수가 필요합니다.

### 📌 성능 팁

- 기본 allocator를 사용하는 vector의 swap은 원소 수와 무관한 상수 시간 교환입니다.
- 클래스 전체의 교환 비용은 각 멤버의 교환 비용에 따라 달라집니다. 고정 크기 배열은 원소별 교환이 필요할 수 있습니다.
- 효율적인 이동 연산이 이미 있다면 기본 std::swap도 충분히 빠를 수 있습니다.
- 직접 정의한 swap은 교환할 상태를 명시하고 불필요한 임시 객체 생성을 줄이는 데 유용합니다.
- 사용자 정의 allocator를 사용하는 컨테이너에는 allocator 전파·동등성 조건이 있으므로 기본 allocator 예제와 구분합니다.
